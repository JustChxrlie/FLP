# Frozen Legacy

Hockey career simulator (browser).

## How to run

**Recommended** (local server):

```bash
cd hockey-career
python3 -m http.server 8080
```

Open http://localhost:8080

Or: `npx serve .`

Opening `index.html` via `file://` can fail in some browsers. Use a local server.

## How to play

1. Click an **Empty Slot**
2. (Name is auto-filled) Pick **position** if you want, or keep Center
3. Click **Start Career**
4. In the hub: **Play Next Game** or **Play Rest of Season**
